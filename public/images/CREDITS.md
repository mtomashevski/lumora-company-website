# Image provenance

The active website uses supplied local Lumora activity photography from:

- `experiences/macedonian-heritage/`
- `experiences/vodno-matka/`
- `experiences/ohrid-bitola-debar/`
- `experiences/skopje-ohrid-2-day/`
- `experiences/lake-ohrid/`

The final official supplied mark is `brand/lumora-logo.png`, served unchanged with transparency preserved. The superseded prototype JPEG was removed from this publishing candidate. Travel files use their original names and AVIF/WebP formats. No supplied portraits have been identified for the managing directors, so that section remains text-only.

The website's data maps every photograph to its matching activity. Home, About and destination imagery is drawn from the activity collection. The business should confirm publication rights and any required photographer attribution before launch.

The old stock-image pairs in the root `experiences/` and `hero/` directories are no longer referenced by the customer website. Their original sources were Unsplash photo IDs 1464822759023-fed622ff2c3b, 1476514525535-07fb3b4ae5f1, 1432405972618-c60b0225b8f9, 1513622470522-26c3c8a854bc and 1551632811-561732d1e306. See https://unsplash.com/license for their source terms. The unreferenced stock-image files were removed from this publishing candidate; their provenance is retained here.

`fallback.svg` is the original project landscape illustration, used only when an expected image fails. The unused provisional SVG favicon was removed; the browser icon uses the official logo.
